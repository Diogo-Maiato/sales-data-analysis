# 📊 Análise de Dados de Vendas

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar análise de dados 
utilizando Python.

Foi utilizado um conjunto de dados de vendas de uma empresa, obtido online,
para analisar o desempenho das vendas ao longo do tempo, identificar os
produtos mais vendidos, comparar o desempenho entre diferentes lojas e 
identificar possíveis melhorias ou informações adicionais que possam 
contribuir para uma melhor tomada de decisão no futuro.

##  Objetivos da análise

Durante o projeto procurei responder a questões como:

- Como evoluíram as vendas ao longo dos meses?
- Qual foi o produto mais vendido?
- Qual foi a loja com maior número de vendas?
- Existem diferenças significativas entre as lojas?
- Existem períodos em que as vendas aumentaram significativamente?

##  Tecnologias utilizadas

- Python
- Pandas
- Excel
- VS Code

##  Processo de análise

O projeto envolveu várias etapas:

1. Importação dos dados.
2. Exploração e compreensão do dataset.
3. Tratamento e organização dos dados.
4. Análise das vendas por mês.
5. Análise dos produtos mais vendidos.
6. Comparação das vendas entre lojas.
7. Criação de gráficos para visualizar os resultados.
8. Interpretação dos resultados obtidos.

##  Principais conclusões

A análise permitiu observar que:

- Após o primeiro semestre, as vendas apresentaram uma tendência de crescimento.
- O produto HL164 foi o produto com maior número de vendas.
- A loja 200 apresentou o maior volume de vendas.
- A partir do mês 06 foi possível observar um crescimento significativo das vendas.

Estas conclusões mostram padrões presentes nos dados, mas não permitem,
por si só, determinar as causas do aumento das vendas.

Para compreender melhor as razões por trás destes resultados, seriam úteis
dados adicionais, como preços dos produtos, campanhas de marketing e
localização das lojas.

##  O que aprendi

Com este projeto pratiquei:

- Manipulação de dados com Pandas.
- Agrupamento e análise de dados.
- Criação de gráficos.
- Comparação de produtos, lojas e períodos.
